# 100 ideas, fought to the death

How the 20 features in version 11 were chosen.

## The rules

Every idea is scored 1–5 on four things:

- **Fun:** would a player feel it in the first minute?
- **Fit:** does it only make sense in *real-time* chess (cooldowns, telegraphs, waves)?
- **Fresh:** does it add something the game doesn't already do?
- **Build:** can it ship in one HTML file without breaking balance or mobile?

**Round 1, duels:** ideas fight in pairs inside their category. The higher total survives; ties go to Fit. 100 → 50.
**Round 2, the gauntlet:** the 50 survivors are ranked by total. The bottom 20 die. 50 → 30.
**Final, the cut:** the top 20 survive, but no category may hold more than 7 seats. That way the game gets new runs, new threats and better feel, not just more cards.

Scores are written as Fun/Fit/Fresh/Build = total. A ✝ marks where an idea died.

**Closest calls:**
- **The Clockmaker** (17) lost its seat only because enemies already had three winners.
- **Haste pads** (17) lost to Quicksand on Fresh: a slow zone is a new idea, but a recharge pad is close to Bloodrush.
- **Daily challenge** died on Build. It needs every random roll in the game to come from one seed, which is a bigger job than any single winner. It's the strongest candidate for its own update.
